# Parábola Lab

Laboratório interativo de funções quadráticas para o ensino de Matemática, voltado a estudantes e professores.

**Autoria:** Joice Souza Martins Santos — projeto Matemática & Contexto.

## Funcionalidades

- Aprender passo a passo: coeficientes, concavidade, discriminante, Bhaskara, vértice, máximo e mínimo, domínio, imagem, sinal e monotonicidade.
- Estudo completo para correção de exercícios.
- Construção do gráfico em plano cartesiano quadriculado, com pares ordenados personalizáveis.
- Treino interativo com questões, dicas e correção.

## Executar localmente

```bash
python -m pip install -r requirements.txt
python -m streamlit run app_quadratica.py
```

Desenvolvido em Python com Streamlit, NumPy e Plotly.
